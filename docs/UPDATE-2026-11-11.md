# 贴纸小屋更新 · 2026-11-11

- 素材由 181 件增加到 277 件。新增 96 件原创程序插画与配套纸品，分为咖啡日常、花园来信、慢游记、猫咪午后、星空梦境、节庆心愿六套，每套 16 件。包含 48 件主题贴纸，以及底纹、胶带、边框、标题签各 12 件。
- 六套可编辑成品模板；使用前自动归档当前草稿。
- 独立作品库：命名、保存新作品、更新已打开作品、复制和删除。
- 可携带的 JSON 备份：包含作品使用的自定义图片，导入时重新入库并映射图片引用，支持空素材库恢复。
- 自动保存顺序化，成功后才记为已保存；配额不足时明确报错，同一内容可重试。空白页面、仅背景工程和撤销后的状态也能保存。
- 放大素材卡片、固定内容行高、大图预览、主题筛选和收藏。新素材优先展示。
- 手机布局：模板和素材页面在 390px 宽度下无横向溢出。编辑器保留画布滚动与缩放。

## 存储边界

在线草稿、收藏与作品库仍保存在当前浏览器；不是账户云同步。作品库使用 IndexedDB，包含自定义图片的独立副本。换设备前请在「模板与作品」导出备份；在另一设备导入即可继续编辑。备份针对单个作品，不包含未被作品使用的素材。

本机模式的当前草稿仍通过原 Python 服务保存；新增作品库保存在使用该站点的浏览器中。

## 开发

全量运行 `python tools/make_materials.py` 会生成原素材及新主题素材。仅扩充主题可运行 `python tools/expand_materials.py`。新增集合使用可选 `collection`/`collections` 字段，原素材 ID 与分类契约保持兼容。

运行 `node --test tests/test_workspace.mjs` 验证保存失败重试、写入顺序、模板完整性和备份校验；`tests/browser_static_check.mjs` 包含新增浏览器交互回归。
