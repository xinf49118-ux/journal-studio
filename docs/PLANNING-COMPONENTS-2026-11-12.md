## 从空白页使用

1. 打开编辑器，选择「新建空白设计」。搜索组件名称，或从按用途分组的结构列表选择。
2. 设置位置、宽高、颜色、行列数量。上方会展示当前组件的填写说明，行标题和列标题一行一个。
3. 按组件需要填写日期、周期、目标值／满分、完成比例、数据或连接关系，再点击「添加这个结构」。未填写的记录保持空白；示例库的演示数据不会自动带入作品。
4. 生成后，每条线、节点、标签、格子或扇区仍是独立图层。Alt点击可选组内一项，Shift点击或框选可多选；可修改文字、移动、填色、拆开重组。
5. 选中完整结构后，点击「读取选中结构参数」，修改并重新生成；重新生成会重建该结构，单独改字或填色应先保存模块。操作可撤销。
6. 把组合保存为个人模块，之后可重复插入，也能导出模块备份。整页可加入DIY整册，导出PNG／PDF及打印继续使用现有流程。

横竖排列用于树状结构和时间线。其他组件可通过宽高、行列、拆分和精确摆放继续调整。数字图表不会在改参数时实时更新，需点击重新生成。

## 数据填写例子

数据一般每行一组，使用英文或中文逗号分隔。空白表示未记录，0是有效数值。多余数据会提示调整，不会静默忽略。

| 组件 | 输入例子 | 结果 |
|---|---|---|
| 睡眠时间带 | `23,8` | 从23点睡8小时，分成午夜前1小时及午夜后7小时 |
| 预算对照 | `100,120` | 预算100、实际120，差额为-20 |
| 债务偿还 | `1000,200` | 期初欠款1000、已还200，剩余800 |
| 习惯积分 | `3,2` | 完成3次、每次2分，计6分 |
| 计划实际图 | `60,50` | 在相同刻度下绘制计划60、实际50 |
| 情绪曲线 | 每行一个分数 | 空白点不连线，0分仍显示 |
| 时间分配圆环 | 第一行 `8,8,1,4,3` | 按所填时长比例分区，列标题对应活动名称 |
| 间隔复习 | 第一行 `1,3,7,14,30` | 在开始日期之后的对应天数排期；这些间隔可自行修改 |
| 日历事项 | 行标题填 `12:缴费` | 在所选月份的12日显示事项 |

加权决策矩阵：行标题填写指标，列标题填写方案。数据每行格式为「权重,方案A评分,方案B评分…」。例如两行`2,6,9`与`3,9,6`，满分10时，加权均分分别为7.8和7.2。某个方案的指标未填全时，该方案显示「未填全」；不会把未知项按0计算。

节点连接：行标题填写节点名称，以出现顺序编号；连接每行填写如`1,2`、`1,3`。树、任务依赖和顺序链拒绝循环，关系地图允许交叉和循环连接。最多16个节点、64条连接。

## 范围与限制

- 所有组件都是工坊独立绘制的数字结构，可编辑、组合、导出，不包含品牌原版图案。
- 事件对照、鱼骨和因果链用于记录自己的判断，不自动推断因果；状态图只按输入数据画图。
- 预算、积分、欠款等按填写数据计算；未填全时合计显示缺项。日历使用真实月份和闰年日期。
- 单组件最多900图层，单页最多1000图层；过密时会提示减小数量或加大尺寸。不同组件还设有便于阅读的节点或周期上限。
- 预览库中的数值为演示数据。作品、个人模块仍保存在本机或当前浏览器，跨设备使用需导出备份。

## 开发与验证

新增实现集中在`web/js/planning-elements.js`，经`design-elements.js`进入同一图层和参数契约；编辑入口在`designer-ui.js`。没有新增依赖、服务器或账户。

模块检查覆盖47种结构横竖生成、ID与分组、备份和参数重建、循环依赖、缺失与0、权重计算、跨午夜睡眠、真实日历及跨年日期、预算与欠款、进度格、比例圆环。相关模块检查64项通过。

新增组件浏览器检查38项通过，包括实际搜索、插入、方向修改和撤销、模块保存插入、参数读回、PNG／PDF和备份、全部47种新组件的真实PNG渲染，以及手机宽度布局。原有圆盘和合并表格的35项浏览器回归检查也通过。纯浏览器检查未重复本机后端的逐像素对比。
