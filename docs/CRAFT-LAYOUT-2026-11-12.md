# 图案花边、局部裁切与贴纸打印排版

[打开编辑器](https://xinf49118-ux.github.io/journal-studio/?tab=editor) · [查看素材、示例与品牌参考](craft-guide.html)

本轮继续提升现有素材的组合能力。内置素材仍为685件，其中印章55枚、贴纸225张；自行生成的花边与效果副本进入「我的素材」，不计入内置数量。

## 裁切与贴纸效果

在「印章与贴纸小工坊」展开「裁切、白边与阴影」。左侧、顶部、宽度、高度按原图百分比填写。例如取右半图：左侧50、顶部0、宽度50、高度100。越界会提示，不会修改页面。裁切使用原图片坐标，生成后保持原图的旋转、翻转、图层顺序与实际位置。

白边宽度0—3mm，阴影深浅0—1；设为0可分别关闭。它们用于纸质贴纸效果，半透明贴与印泥不增加白边。白边像素宽度有120像素上限，极小素材或放大打印时应先试印。预览后点击应用，画布中替换选中的图层，原素材仍保留，可撤销。

## 用一件图案做自己的花边

选中一件素材，展开「图案印章、连续花边」。可先用裁切范围取图案局部，再选连续花边、四周边框或环形花环。整体宽20—100mm、重复2—48个，单个图案旋转角度可调。图案会按可用空间缩小，避免被画布边界裁掉。

默认转成当前印泥颜色；取消勾选则保留原色。预览满意后点击应用，生成独立PNG素材加入页面；透明背景可叠放文字、照片与其他贴纸，也能保存为模块。花环的中心留空，可另加日期或文字。图案花边目前由同一图案重复组成，尚无多种图案交替规则；需要混搭时可分别生成后在编辑器组合。

## 排成可打印贴纸页

建议先新建空白页、选择纸张，再加入一件要复制的印章或贴纸。展开「排成贴纸打印页」，填写单张宽度、张数、页边距和间距。高度按原素材比例计算，按行从左上排列，复制后为正向，保留水平／垂直翻转、透明度与叠放方式。最多100张，每页总图层仍不超过1000。

点击「在当前纸张复制排布」会替换所选图层，并保留页面其他内容；可以一次撤销恢复。放不下时显示当前容量，不会截断或偷偷缩小尺寸。可选矩形剪裁参考线；这是手工裁剪辅助框，尚未生成切割机的轮廓刀线。

示例：A5、单张30mm正方形、页边距10mm、间距4mm，可排列12张并保留余白。完成后到打印页导出PNG／PDF或打印，选择100%实际大小；不要启用打印机的自动缩放到纸张。实体打印前先试印校准。

本轮将印章贴纸参考页从6个品牌扩至9个，新增：[KING JIM / KITTA](https://www.kingjim.co.jp/hitotoki/sp/kitta/lineup.html)、[古川纸工](https://www.furukawashiko-online.shop/c/furukawa-product/item-fp/flakesticker-fp)、[mt / KAMOI](https://shop.masking-tape.jp/)。官方入口用于核对预切胶带、透明贴、和纸碎片贴与胶带等类型；工坊的裁切、花边和排版为独立实现，未内置品牌原版花型或联名图案。
