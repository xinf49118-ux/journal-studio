# 原创设计室 · 2026-11-13

新增三套围绕实际记录流程设计的原创套组；每套有4种可编辑内页、6枚功能印章、4张贴纸。吸收留白、信息层级、套组配色等通用方法，自行构思字段、布局、图案与文案。它们不是品牌原版素材，也没有使用个人收藏中的品牌图案。

[查看12种内页和30件配套素材](atelier.html)。模板入口只定位选择器，应用时保留原有草稿保护流程；素材入口只定位素材库，不覆盖当前画布。

| 系列 | 原创内页 |
| --- | --- |
| 清爽日常 | 三线并行日、缓冲周计划、启动阻力清单、负荷平衡月 |
| 沿途采集 | 路线与感官、物件来历卡、季节采样册、旅后回声 |
| 温暖小屋 | 小屋维护地图、补能菜单、关系关怀页、一餐一刻 |

文字、格线、分区都使用原生图层，可单独改字、改色、移动、缩放、删除和组合。场景装饰也可移除。套组使用各自的专属配色，应用后可继续逐层调整。A5为设计基准，支持既有尺寸适配、整册DIY、备份、PNG/PDF导出与浏览器打印。

三张场景贴纸通过内置imagegen生成；其余9张配套贴纸和18枚印章由工坊程序绘制。场景提示词和方式记录在[生成记录](atelier-prompts.json)。生成原图另保存在本机工作区 `outputs/atelier-sources`，公开项目使用保留透明通道的640px版本。印章提供日期备注、勾选框或记录线三种功能区，可继续使用工坊的印泥与缺墨效果。

当前内置目录为99种内页、907件素材、28套主题；其中381张贴纸、121枚印章。结构组件仍为72种，新增成品内页不计为新增结构组件。生活主题贴纸筛选保留原有96张历史批次；原创三套可从主题筛选或设计室进入。
